# 🚗 Car Explorer App

A web application that allows users to explore car makes, vehicle types, and models based on selected criteria.

## ✨ Features

* Select car make
* Filter by manufacture year
* View vehicle types
* Browse available models

## 🛠️ Tech Stack

* .NET Core Web API
* External Vehicle API (NHTSA)
* Docker
* AWS Deployment (Free Tier)
